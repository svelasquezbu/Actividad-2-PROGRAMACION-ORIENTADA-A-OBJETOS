## 🛠️ Contenido del Repositorio

El proyecto está compuesto por los siguientes archivos en Java:

1. **`Persona.java`** (Ejercicio 2.1 - Página 63): Modela una persona con sus datos básicos y método de impresión.
2. **`Planeta.java`** (Ejercicio 2.2 - Página 66): Implementa atributos astronómicos, tipos enumerados, cálculo de densidad y clasificación de planeta exterior.
3. **`Automovil.java`** (Ejercicio 2.3 - Página 66): Modela el comportamiento de un vehículo, controlando aceleración, desaceleración, frenado y cálculo de tiempo de llegada.
4. **`PruebaFiguras.java`** (Ejercicio 2.4 - Página 86): Implementa clases para distintas figuras geométricas (Círculo, Rectángulo, Cuadrado y Triángulo Rectángulo) calculando áreas, perímetros y tipos de triángulo.
5. **`CuentaBancaria.java`** (Ejercicio 2.5 - Página 95): Simula el manejo de una cuenta de ahorros o corriente con operaciones de consignación, retiro y consulta de saldo.
